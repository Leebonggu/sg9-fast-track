# 인쇄 명단 레이아웃 — 화면 말고 실측으로

인쇄 레이아웃은 브라우저 화면으로 판단하면 반드시 틀린다. 수정 전후로 실측 도구를 돌린다.

## 실행 (`web/`에서)

```
npm run verify-print
```

- `web/scripts/verify-print-layout.mts` (읽기 전용) — page.tsx의 `<style jsx global>`을
  그대로 뽑아 라이브 최악 케이스(가장 긴 이름·연락처·5인 공유)로 PDF를 렌더하고
  넘치는 셀·행 높이·장당 행수를 숫자로 낸다. 출력물은 `web/out/`(gitignore)
- 수정 → verify-print → 넘침 0 확인 → 커밋. 이 순서를 건너뛰지 않는다

## 실측으로 확정된 규칙 (되돌리지 말 것)

- **`word-break: keep-all` + `overflow-wrap: anywhere` 반드시 세트로.**
  keep-all 없으면 이름 한가운데가 끊기고("문기성/제이슨"), anywhere 없으면
  11자 법인명이 셀을 넘쳐 옆 칸을 침범한다
- **컬럼 폭 합계는 본문 폭보다 1mm 적게** (186mm 본문이면 185mm) —
  border-collapse 바깥 테두리가 밖으로 나가 실폭이 커진다(실측 186.3mm)
- 상태 컬럼 폭 기준은 본문(O/전/X)이 아니라 **머리글**("동의서" 3자)
- A4 세로, 동 제목 매 장 반복, 장당 27행 (2026-08-21 확정)
- 동의 표기는 종이·전자 겹침: `O`(종이) / `전`(전자) / `O전`(둘 다)

## 함정

- 표시 로직만 바꾼 경우 sync 불필요 (시트에 쓰는 값 없음)
- 개별 이름은 6자 이하가 99.8% — 이름 줄바꿈 대응은 예외 케이스 기준으로 설계하지 말 것
