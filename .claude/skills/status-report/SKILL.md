# 동의 현황 공유 요약

`/unified` 현황판과 같은 판정 함수(unified-utils)를 쓰는 집계 스크립트라 화면 숫자와 어긋나지 않는다.

## 실행 (`web/`에서)

```
npm run status-report
```

- 출력: 신통·입안 동의(종이/전자/합산), 개인정보, 신분증, 설문, 단톡방·반대, 실거주 집계
- **집계 숫자뿐(개인정보 없음)이라 출력 그대로 단톡방 공유 가능**
- 마지막 두 줄 "(참고·내부용)"은 독려 작업용 — 공유 문구에서 빼고 전달

## 주의

- 통합현황은 sync 시점의 스냅샷. 출력 첫 줄의 "동기화 기준" 시각이 오래됐고
  최신 수치가 필요하면 **safe-sync 스킬로 sync 먼저** (매일 23시(KST) Vercel cron도 돈다)
- 등록/임포트 직후 공유용이면 econsent-registration-check가 뽑는 명단과 함께 전달하면 좋다
- 개별 세대 이름·연락처를 섞어 달라는 요청이면 이 스크립트가 아니라 /unified 필터나
  docs/raw 리포트를 쓰고, PII 규칙(커밋 금지)을 지킨다
